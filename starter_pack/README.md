# Starter Pack — Plataforma (ordem corrigida M0–M9)

## Como usar
1. Crie o repo: `mkdir platform && cd platform && pnpm init`
2. Copie `.cursor/`, `docs/` deste pack para a raiz do repo.
3. Copie a Parte 0 da BLUEPRINT_TECNICA_DEFINITIVA.md para `docs/arch/visao-geral.md`.
4. Abra no Cursor e execute as tasks 001–012 (M0) — veja `TAREFA_ATUAL.md`.
